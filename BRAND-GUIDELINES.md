| ----------------- | --------- | ---------------------------------------- |

| **Warm Beige**    | `#DAD2BF` | Primary brand color, buttons, highlights |

| **Light Gray**    | `#E6E6E6` | Subtle backgrounds, borders              |

## Color Implementation

### Tailwind CSS Classes

- `bg-brand-primary` → Warm Beige (#DAD2BF)
- `bg-brand-charcoal` → Deep Charcoal (#1D2026)
- `bg-brand-dark-charcoal` → Dark Charcoal (#393335)
- `bg-brand-light-gray` → Light Gray (#E6E6E6)
- `bg-brand-slate` → Slate Blue (#373C49)
- `bg-brand-forest` → Forest Green (#3F4740)
- `bg-brand-bronze` → Bronze (#60533C)
- `bg-brand-rose` → Dusty Rose (#D8C5BF)
- `bg-brand-powder` → Powder Blue (#BFCBD6)

### Usage Guidelines

- **Primary Colors**: Use for main brand elements, primary CTAs, and key visual hierarchy
- **Secondary Colors**: Use for supporting elements, hover states, and subtle accents
- **Contrast**: Ensure sufficient contrast ratios for accessibility (4.5:1 minimum for normal text)

## Typography Hierarchy

- **Headlines**: Dark Charcoal (#393335) on light backgrounds
- **Body Text**: Dark Charcoal (#393335) with good contrast
- **Light Text**: Pure White (#FFFFFF) on dark backgrounds
- **Accent Text**: Bronze (#60533C) for highlights and links

## Button Styling

- **Primary Buttons**: Warm Beige (#DAD2BF) background, Dark Charcoal (#393335) text
- **Secondary Buttons**: Transparent background with Bronze (#60533C) border and text
- **Ghost Buttons**: Semi-transparent white background on dark sections

## Background Combinations

- **Hero Sections**: Deep Charcoal (#1D2026) with white text
- **Content Sections**: Pure White (#FFFFFF) with dark text
- **Accent Sections**: Light Gray (#E6E6E6) for subtle emphasis
- **Card Elements**: Gradient combinations using primary and secondary colors
